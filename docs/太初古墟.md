# 太初古墟与装备

现有玩家、伪玩家和敌人的战力规则保持原样，世界Boss继续按原有平均境界计算血量。本轮只将新打造太初六件装备的原生属性提高到初版的3倍；境界、万魂、旧装备及战力公式保持原样，太初入口继续关闭。已有同名装备的完整属性快照不自动重写，交易、搜刮和继承继续保留原值。

本功能的总开关是插件目录下 `config/taichu.json`。交付时保持关闭：

```json
{
  "enabled": false
}
```

完善后将 `false` 改为布尔值 `true` 即可开放玩家入口、天工坊及伪玩家行为。首次部署新文件后建议重启机器人，使新应用和规则完成加载；后续开关读取无需改代码。配置缺失、JSON损坏、字符串 `"true"` 都视为关闭。关闭时不产生太初收益、不扣太初耐久、不建设或维护天工坊；已有装备、附魔、设施及未结束探索数据保留。伪玩家的太初占用标记会释放，重新开启后在其可行动时续跑；超时探索按败退结算。

| `#修理太初 武器` | 修理穿戴部位，也可用完整或唯一前8位装备ID |

## 探索与费用

普通、困难、绝境每人分别支付 **20000、50000、100000灵石**，各含100精力和本趟4份补给。难度采用固定敌人强度65000、150000、300000，不根据入场玩家战力自动抬高。战力来自游戏统一计算入口。

每趟18个阶段，依次经历择路、阵纹、镇守、残殿和四阶段太初殿。铸兵路线出断界/承天，镇魂出镇神/寂轮，沧溟出无相/踏虚相关产物。阵纹提示给出正确供能；也可耗材镇压或强破。镇守与Boss的护盾、蓄力、召唤、标记分别需要破盾、打断、攻击、护持。失误增加失控并降低稳定度。

精力贯穿全程。补给每份恢复30精力；额外背包“古墟补给”需要实际制作和消耗。残殿搜索增加收获，封存让部分普通材料在失败或撤退后仍保留。默认每次封存最多10件，四件套提高到12件。6小时未完成自动判败退。

每人每周最多两次核心奖励，按北京时间周一换周。各难度每次核心奖励均为1枚太初印；图谱碎片、部位核心及核心碎片沿用各难度原规则。核心奖励不受寻宝影响。没有核心额度仍可获取普通材料。领奖记录同时防止重复领取和并行队伍超额占用。

## 六件套打造

六件为太初·断界（武器）、太初·镇神（头盔）、太初·无相（胸甲）、太初·承天（裤子）、太初·踏虚（鞋子）、太初·寂轮（戒指）。每件需同部位“攻势”装备胚子一件、太初印8枚、对应图谱和部位核心各一件，以及各自跨玩法材料。

每件打造固定收取 **1000万灵石、1000宗门贡献**，需要本宗一级以上天工坊且位于本宗大区。具体材料数量以 `#太初配方` 和 `components/taichu_data.js` 为准。条件缺失不会部分扣料。打造不随机生成附魔。

新打造装备的原生属性如下，不含附魔与套装效果：

| 装备 | 部位 | 攻击 | 防御 | 生命 |
|---|---|---:|---:|---:|
| 太初·断界 | 武器 | 7200 | 0 | 0 |
| 太初·镇神 | 头盔 | 0 | 4800 | 18000 |
| 太初·无相 | 胸甲 | 0 | 6000 | 27000 |
| 太初·承天 | 裤子 | 0 | 5400 | 22500 |
| 太初·踏虚 | 鞋子 | 0 | 4200 | 18000 |
| 太初·寂轮 | 戒指 | 3600 | 3000 | 18000 |
| 合计 | 六件 | 10800 | 23400 | 103500 |

沿用装备战力公式“攻击×2＋防御×2＋生命÷5向下取整”：六件原生属性合计 **89100** 战力，满耐久穿齐且无附魔时，计入六件套防御/生命＋30%后为 **109350**。六件套效果本身贡献20250装备战力，只按太初装备本件原生防御和生命计算。合法满战斗附魔时为 **181650**：武器锋锐Ⅴ，四件防具坚甲Ⅴ与生机Ⅴ，戒指锋锐Ⅴ与生机Ⅴ；目前仍无附魔获取或安装入口。

本次换装以毕业角色约25%～35%的整体提升为调校目标，并非每个角色固定获得这一比例。一个无附魔、满耐久样本：567级境界84900，九阶万魂幡内主魂与三副魂均为567级、合计169800，彩宠9000，万魂幡固定攻击500折合1000战力；原有满属性攻势四防具及戒指、攻击3000的彩武合计16920装备战力，换装前为 **281620**。换成上述太初六件套后为 **374050**，增加92430，约 **32.82%**。样本不含额外增益与伤势；其他资产保持一致。实际提升随原装备、境界、魂、灵兽及当前状态变化；满附魔样本不作为这次无附魔换装目标的承诺。

天工坊基础费用20万灵石，材料为凤羽玉20、造梦神玉5、乾坤阵晶5；沿用设施规则，初建灵石×2、材料×5，后续升级灵石×目标等级平方、材料×目标等级。天工坊玩家与伪玩家同价，AI建设须保留维护及战争预算；关闭开关暂停收费。

## 附魔与套装计算

每件最多两个强化槽、一个养护或探索槽。附魔只影响装备本身或指定古墟行动，不修改玩家基础属性，也不按角色总战力加成。

| 附魔 | 每级效果，最高Ⅴ |
|---|---|
| 锋锐 | 武器/戒指本件原生攻击＋10%，Ⅴ为＋50% |
| 坚甲 | 四件防具本件原生防御＋20%，Ⅴ为＋100% |
| 生机 | 防具/戒指本件原生生命＋20%，Ⅴ为＋100% |
| 破阵 | 武器在古墟破盾、破阵的行动效果每级＋10% |
| 镇禁 | 头盔耗材镇压消耗每级－5% |
| 耐久 | 本件耐久损耗除以（等级＋1），Ⅴ为原来的1/6 |
| 轻灵 | 鞋子拆阵精力消耗每级－5% |
| 寻宝 | 头盔/戒指普通材料收益每级＋5%，同名取最高 |

两件/四件/六件套分别给已穿太初装备的原生防御、生命额外加10%/20%/30%，档位不叠加。与附魔按同一原生属性相加，例如生机Ⅴ加六件套为原生生命的230%。四件套提高封存容量；六件套每趟可用一次“定墟”抵消失控，换装或修理不会刷新。

## 耐久与维护

每件独立初始耐久1000，低于200提示维护；归零时本件属性、附魔及套装计数失效。普通实际战斗和古墟行动结算扣耐久，查看信息、伤害预估和重复结算不会扣。耐久附魔的分数损耗累计保留。

修理每不足100耐久向上取一份，含分数损耗：每份月魄石10、流光玉5、凤羽玉1、灵石5000、贡献2。修理恢复至1000并保留ID和附魔。应急包恢复单件200耐久。

## 伪玩家与存档

具备普通档安全余量的可行动伪玩家会选择缺少的太初装备作为长期目标，定向采购材料并保留完整配方需求；不符合战力的新手不受该目标影响。它们实际支付入场费，走同一套18阶段、补给、掉落、封存和每周核心额度；返回本宗天工坊后按同配方打造与修理。副本期间与秘境、万魂窟、战争、修炼、交易、跨区等外部行为互斥。

玩家副本与奖励账本位于正式存档根目录的 `taichu/`，采用版本检查、原子写入及备份恢复；跨背包、金钱、贡献和副本的操作用持久事务记录恢复。伪玩家的探索、背包、金钱和奖励额度同存于其群世界档。关闭功能不会删除这些数据。
