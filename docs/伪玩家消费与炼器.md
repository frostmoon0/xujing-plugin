# 伪玩家消费与炼器

修为丹按未来四重境界的灵力需求批量服用，每次最多99颗，同时受背包实有数量、下一重灵力缺口和累计池容量约束。每颗仍提供200灵力；已到瓶颈、满级或没有容纳空间时不再浪费丹药。

连续突破按每一重分别消耗破障丹并判定，失败即停，保留剩余丹药并调息5分钟。七档气运加成沿用原规则，最高档仍可能失败。自然突破率已经更高时不吃丹降低成功率。

购物先使用已有装备和功法，再根据真实需求购买。首选缺货时继续检查其它有提升的装备、功法和成长丹药；丹药可以按缺口批量采购，以实际交货数量扣钱、扣库存、计税。满级不采购成长丹药，自己的刚需丹药和制造材料不作为闲置物卖出。战斗丹药生效期间不重复服用。

普通彩装作为高优先级目标，先于一般法宝中间物筹料和制造。配方与玩家相同：五种非彩色矿物各1份炼制随机红装；6造梦神玉与1件背包红装制造随机彩装。市场有现成红胚时优先求购，不需要先炼胚。制造不额外增加玩家配方之外的灵石费用，购买材料按真实持货者报价付款。

成品沿用玩家的随机部位、随机属性生成器，随后自动择优穿戴。穿戴中的红装及太初目标预留胚子不作为耗材；同名红装优先消耗较弱的属性组。每轮最多推进三次炼器流程，有产出后间隔30分钟，全套彩装完成后停止普通彩装筹料。缺少材料时不会凭空生成成品，也不会恢复已删除的伪玩家专属鬼市。
