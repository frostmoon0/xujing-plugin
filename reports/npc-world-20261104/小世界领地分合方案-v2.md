# 小世界长期演化：领地分合方案 v2

2026-11-04方案；2026-11-05已落实第一批及发展节奏调整。下文保留设计记录，实际实现与验证见 world-v2/实现与回滚说明.md 和 world-v2/模拟复核.md。

## 一、按你的意思重新确定目标

“合”是地盘逐渐被一个宗门占领，形成霸主，甚至一宗占满天下；“分”是原本集中的地盘又被其他宗门夺走，形成几家割据、彼此争夺。

本方案去掉宗门自动合并、自动归附，也不要求强宗通过强制内部分裂来打破统一。宗门以独立身份发展，通过真正的攻打改变地图。

希望出现的过程是：多宗争地 → 强宗扩张 → 地盘集中 → 强弱发生变化 → 其他宗门夺回部分地盘 → 再次割据 → 新强宗崛起。

这是可能反复发生的演化过程，不是每隔几天必须重演的剧本。强宗经营得好，没有足够强的对手时，可以长期统治。

## 二、保留的设定与已有基础

1. **总部被攻破，原宗门永久灭门。** 不通过继任、换名、原宗主归来恢复原宗门。
2. 攻打小区胜利，只改变该小区归属，宗门继续存在。
3. 当前宗门战已经支持：宗门一方攻破敌宗总部后，败方现有领地交给胜方的领地归属宗门；联盟沿用实际贡献决定归属。玩家小队没有占地宗门时，败方地盘无主化。继续沿用，不将灭门后的土地一律清空。
4. 保留固定补人、399人口上限、80%散修/20%入宗、弟子死亡替补，以及你刻意给NPC的成长与资源扶持。
5. 保留现有数字交互。NPC的风险判断不限制玩家主动选择冒险。
6. 不替真人决定入宗、任职、退盟或出兵。NPC宗门对玩家宗门的既有行为范围不借此扩大。

## 三、先解决人物与宗门历史留不住的问题

### 1. 危险行为需要实际条件和胜负

上一轮三个新世界七日后只有25、22、33人。世界甲累计死亡1176人次，新增1053人次；日常致死行为是主要消耗。

建议仇杀、劫杀、寻仇接入一致的行为检查：

- 在世，且不处于参战、被俘、关押、挖矿、秘境、在途等冲突状态，才能主动行动。
- 即时冲突要求同一大区。追远处的仇人先走现有跨区流程，不能抽中名字就隔空杀人。
- 复用现有统一战力与胜率口径，计入装备、灵兽、功法、丹药和伤势，不另造公式。
- 明显不敌时可以暂避、修炼、等机会。普通冲突更多产生负伤、财物损失、逃脱或结怨；明确死仇与凶狠人物仍可能杀人。
- 复用现有伤势恢复；增加个人危险行动间隔、同目标重复遭遇限制。间隔数值通过长跑确定。

现有击杀还可能让全宗门人和亲友一起结仇。建议区分本人死仇、亲友复仇意愿和宗门敌意，再由性格、羁绊与现实能力决定是否追杀，避免一场冲突迅速扩成所有人的无限追杀。

保持日常事件活跃；危险行动不成立时，可以选择其他适合当前人物的活动，不额外补一次随机击杀来凑事件数。

### 2. 总部完好，换宗主不等于宗门消失

当前旧逻辑会在宗主、副宗、太上全死后，即使还有普通门人，也清空地盘，随后用旧编号换名重建。

| 实际状态 | 拟议处理 |
| --- | --- |
| 总部完好，宗主死亡，有继承人 | 原宗门继任，保留地盘和历史 |
| 核心职位空缺，仍有普通门人 | 现有门人暂代掌事，再结合实力、资历、忠诚与羁绊继任；职位不凭空提升修为 |
| 原宗主还活着，只是在途、秘境或被俘 | 不当作死亡；紧急事务交给可行动门人，不仅因缺席另判灭门 |
| 确实没有任何在世成员 | 自然消亡，清理占地和关系；后续新势力使用新身份 |
| 总部已被攻破 | 永久灭门优先，终止继任和旧编号重建 |

暂代掌事不提供保护期、额外门人、免费守军或免费治疗。普通弟子继任后仍可能守不住地盘。

玩家主导宗门不交给AI自动夺权；真人继承仍保留玩家管理边界。混合宗门不能因NPC核心死亡，直接清除仍在宗内的真人身份。

### 3. 转投不应仅因职位变化压低修为

普通入宗已经保留修为，但叛宗转投、开宗拉同伴、部分战俘收编和招人路径仍有旧的弟子修为截断。

建议统一为：职位决定权限，实际修为继续属于本人。高手转投弱宗，才可能使弱宗成长为新的对手。

这会同时影响NPC宗门和玩家宗门招收NPC，属于明确提出的行为变化，不改真人角色修为；不追溯猜测并补回历史上已经损失的修为。

## 四、让地盘能够真正集中

### 1. AI出兵前按实际阵容复核

选敌的可用总兵力估算，可能与意愿、人物状态、封锁和预算约束后的实派阵容脱节。

建议在AI提交前比较：实际调兵计划及已落实支援，对比目标可组织守备与设施加成。盟友名单不等于实际援军，尚未行动的真人也不算必定出战。

第一轮先沿用当前普通目标0.85、双方均至少4块地时0.7的最低战力比，修正估算与实派脱节，再按实测讨论阈值。战力比不是胜率保证，势均力敌仍可输。

复核失败发生在扣费、耗丹、占用人物和改变敌对关系之前。可以换目标，但设置短暂重试间隔，避免每分钟重复失败。

### 2. 扩张要有持续目的

宗门先判断当前需要守宗、休养、经营还是扩张，再决定是否选敌。扩张结合真实收益和调兵条件：

- 可打赢的无主地。
- 已有地盘所在大区内、调兵费用可负担的其他地盘。
- 能改善收入或扩大实际控制范围的小区。
- 有明确机会攻破的敌宗总部。

当前地图按大区组织，没有完整的小区道路邻接图；先按大区和费用判断，不凭空加入接壤、道路包围或补给线判定。

同一目标可以持续争取；战败、预算变化、增援或停战后重新评估，不能为了坚持目标一直送兵。

### 3. 总部战改变大局

强宗可以逐块夺地，也可以攻破敌宗总部，一次接收其现有地盘，促成大范围的“合”。

沿用现有灭门与贡献归属结算，不增加自动合并宗门，也不把原宗门全部门人无条件送给胜方。

## 五、让集中的地盘有机会被重新瓜分

### 1. 真实人员和成本构成防守压力

先让同一批门人面对已有的出征、防守、负伤、被俘和调兵费用约束。

AI出征前考虑总部剩余守备；多处受袭时选择守哪里、调谁去、是否接受边地失守，不能把一个高手复制到多个战场。

现有宗门调兵可以支付费用直接到目标大区，本方案第一阶段保留，不宣称已有完整行军与补给制度。是否增加驻防或额外远地治理费用，等已有约束实测后再定。

不预设占19块地就必须衰落。人员、资源和安排足够，就应该守得住。

### 2. 弱宗找机会，避免硬撞霸主

暂时不敌时积蓄、招人、改善装备、争夺别处可打的地盘，或与有共同威胁的宗门合作。

霸主主力被另一场战事实际占用，或高手负伤、被俘、宝库不足时，其他宗门重新评估夺地机会。每次仍需实派复核。

防守优先级必须与进攻判断一起设计：边地失守可以接受，总部失守就是灭门；不能无条件为第一块受袭小区押上全部力量，随后失去保护总部的判断。

### 3. 外交给局势留下发展时间

对同一宗门对维护一致的当前关系、形成时间和停战期限：

- 盟友与敌对互斥，双方同时更新；新宗门不继承已灭门旧宗门的关系。
- 同一次推进不对同一对宗门反复改变关系。
- AI不会刚结盟就无原因随机退盟。共同威胁、实际援助、收益和背约影响后续选择。
- 可试验6小时的AI普通退盟观察期。真人主动退盟不因AI观察期被禁止，明确背约也可以让AI提前退盟并承担后果。
- 可试验议和后6小时的双边停战，覆盖双方总部及所有小区，防止刚停一场又换目标重开。停战不阻止第三方攻击。

上述6小时均为候选值，沿用现有绝对时间口径，并在保留夜间暂停的长跑里验证，不新增另一套世界时钟。

共同停战约束适用于NPC与玩家宗门，这是会影响玩家规则的一项。小队入口也检查成员当前所属宗门与目标的停战义务，避免用小队身份绕过；真正无相关身份的第三方不受这对宗门的协议限制。需要单独测试各入口。

现有盟友协攻可以继续完善。自动联合防守属于新增机制，不能当作现在已有；后续如增加，必须真实出人、付费、承担损失，也可以因自身受袭而不援助。

### 4. 新挑战者靠实际成长形成

人才成长、转投、现有散修开宗及宗门补建，可以提供挑战者。先看这些能否使弱宗逐步具备争地能力，不新增强制内乱或自动合并。

保留扶持时，分别记录已有角色开宗，以及系统补建生成的新人物和启动资源。不能将系统补出的宗门全部说成自然成长。

## 七、补人机制联动

原世界甲的人口账：

148 + 267定时入世 + 579弟子死亡替补 + 177旧式重建新增 + 30其他入宗新增 − 1176死亡 = 25。

减少弟子死亡会减少立即替补，停止旧式换皮也减少新宗主生成。因此不能把避免的死亡数直接加到最终人口上。

第一阶段保留补员优势，不通过加快补人掩盖失衡。分别记录各类新增、死亡及净流量，尤其观察新入世散修能否度过最弱阶段。

高人口端也要检查：接近399后定时入世停止，老人物是否永久垄断实力，新人物是否仍有成长空间。人口满员本身不等于小世界成功。

已有七日实跑来自147/148人开局的新世界。正式存档只读检查可见数百人规模的世界，不能将新档曲线直接当成现有世界的未来预测。

- 外交只允许一个权威写入入口。旧allies/enemies若继续供兼容读取，由同一入口同步，不能各自独立改写。

## 十、怎样验证领地真的分分合合

先在隔离目录做规则回归，再从相同起点、多随机种子推进7日与30日。机制变化会使随机轨迹分叉，比较多组分布与完整因果记录，不将单次差值当精确因果。

样本包括原有新世界、低人口场景、近399人口场景及现有世界完整副本。副本带齐相关世界、灵兽、秘境等行为状态；含真人的世界标注无后续真人操作，不删除真人后仍称原世界。

| 维度 | 观察什么 |
| --- | --- |
| 人口 | 出生死亡完整账目，各来源新人留存与老人物成长，避免低人口换人循环，也观察满员端 |
| 地盘集中 | 最大宗门占地份额如何上升，哪些真实战争带来集中 |
| 地盘再分散 | 集中地盘是否经真实战争转给多个宗门；无主清空、旧宗门换皮不算有效分合 |
| 格局连续性 | 逐小区记录原主人、新主人与对应战事，区分一统小区与灭尽其他宗门 |
| 宗门历史 | 继任延续历史，总部被破后永久退出，旧ID不被错误复用 |
| 决策 | 实派与风险判断一致，不敌有其他选择，仍允许合理败仗 |
| 外交 | 敌友不重叠，同轮不随机结了又退，停战不被换目标或小队绕过 |
| 完整性 | 人物行动独占，无凭空复活、负预算、重复占地或重复奖励，俘虏状态完整 |

如果长跑始终稳定一统，也如实报告原因，再讨论是否需要额外机制；不写死剧情保证每个种子必定轮回。本轮仅形成方案文档，没有修改业务源码、配置或正式存档。
